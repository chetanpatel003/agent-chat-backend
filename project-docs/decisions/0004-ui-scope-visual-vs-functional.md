# 0004 — UI scope: functional chat vs. visual-only nav

**Decision:** build the complete, functional chat experience first. For Projects, Scheduled, Computer, Voice, Templates (visible in the reference's sidebar/top bar/home grid), reproduce their visible navigation/UI only — no underlying workflow — unless the evaluator confirms they're in scope.
**Why:** assessment requires visual fidelity to the reference, not that every visible feature be independently functional. Avoids building unrequested features (explicitly warned against) while keeping cloning fidelity intact.

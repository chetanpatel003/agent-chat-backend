Already sound at audit time (T): exactly-once settlement (guarded claim + unique ledger key),
crash after provider success (persisted run id → re-entry/sweep reconcile), archival retries
(5 attempts, permanent vs transient), settlement failure recovery, schema-validated provider
responses, identical agent and direct execution paths.

## Owner decision (2026-11-03)
All six fixes accepted. Billing policy: a COMPLETED run with no usable media
(`PROVIDER_OUTPUT_INVALID`) is charged Magica's actual reported usage, like an explicit provider
failure; an unknown outcome (`PROVIDER_OUTCOME_UNKNOWN`) is never charged and never resubmitted.
Settlement and ledger implementations unchanged. Details: decision 0019.
